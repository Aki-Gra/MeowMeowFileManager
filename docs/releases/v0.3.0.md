# MeowMeow File Manager v0.3.0

First signed Android release of MeowMeow's offline file manager.

Highlights:
- File explorer in List, Large Icons and Thumbnails views.
- In-app PDF page reader, images and DOC/DOCX/ODT/text document previews.
- Swipe through PDF pages and nearby images; pinch/zoom and panning.
- Share the original file from viewer and the three-dot file menu.
- Open supported file formats from other Android apps.
- Search, duplicate analysis, cleanup and file operations.
- Reader hardening and safe bounded resource usage.

The DOC/DOCX/ODT reader provides extracted text, not full Word layout.
Animated GIFs currently display their first frame. There is no
automatic cloud upload.

Installing over a debug test APK may fail because it uses a different
signature. Remove that debug installation once if required. Keep this
release signing key for future updates.
